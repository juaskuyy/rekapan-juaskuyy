# Rekapan Juaskuyy

Dashboard rekapan sewa room apartemen untuk NikiRoom dan VinzzRoom.

## Stack
- HTML/CSS/JavaScript vanilla untuk prototype UI
- Siap diadaptasi ke Cloudflare Pages/Workers + D1
- Tidak menggunakan R2

## Catatan
Versi awal ini berfokus pada UI dan struktur fitur. Data demo tersimpan di localStorage agar bisa langsung dicoba.
